Description

This is an interactive demo tool for understanding how 2D image Fourier transform works.

This work is inspired by Prof. Ohzawa's lecture. →video

How to use

  • Edit the mask on the Masked spectrum or Mask canvas:
    • Erase mask: Mouse left-drag / 1-finger drag
    • Restore mask: Mouse right-drag / 2-finger drag
    • Change brush size: Mouse wheel / brush size slider
  • Change the input image by clicking a thumbnail or loading a file / URL.
  • Change the mask by clicking a thumbnail or loading a file / URL.

Features

  • Interactive mask editing (mouse and touch)
  • Real-time inverse Fourier transform
  • Load image from file or URL
  • Load mask from file or URL

Used technologies
